Rust · Pre-alpha

SteelMC

一个用 Rust 编写的 Minecraft Java 版服务器。世界生成已经相当完整， 生存玩法与实体行为仍在持续实现中——适合体验与测试，不建议替换正式服务器。

连接地址

客户端版本需与服务器一致（当前目标为 Minecraft 26.3 对应的 Java 版协议）。

配置与数据

  • 服务器配置：config/config.toml
  • 世界配置：config/worlds.toml
  • 存档目录：saves/
  • 日志目录：logs/

修改配置后重启应用生效。默认 online_mode = true， 需要正版账号登录。
